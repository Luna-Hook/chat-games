# ChatGames

ChatGames adds chat-based games to Paper servers. This repository is a fork of the MIT-licensed [RareHyperIon/ChatGames](https://github.com/RareHyperIon/ChatGames) project and retains the upstream author and license notice.

The [Modrinth project page](https://modrinth.com/plugin/chatgames) remains the public upstream reference. The GitHub page embedded in the upstream metadata is currently unavailable or broken.

Build with Java 21 and Maven: `mvn package`. The Paper plugin is produced by the `chatgames-paper` module.
